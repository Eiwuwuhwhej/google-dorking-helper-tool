Google Search Operators Quick Reference

Essential syntax standards and behavioral rules.

Operator Syntax Behavior Example
site: site:domain.com Restricts search results to the designated domain or path. site:nasa.gov
filetype: filetype:ext Restricts document format by extension. Synonymous with ext:. filetype:pdf "financial report"
intitle: intitle:"phrase" Requires specified terms within the page HTML <title>. intitle:"index of /"
allintitle: allintitle:a b c Requires all specified words to appear within page title. allintitle:admin dashboard login
inurl: inurl:path Restricts search to text in the URL path. inurl:wp-admin
allinurl: allinurl:a b c Requires all words to appear in the URL address. allinurl:api v1 auth
intext: intext:"phrase" Restricts match to the visible body copy of the document. intext:"DB_PASSWORD"
" " "exact phrase" Requires exact word order without stemming or synonyms. "confidential disclosure"
- -term Excludes documents matching the negative term. site:example.com -www
OR / | a OR b Logical disjunction. OR must be capitalized. filetype:pdf OR filetype:doc
after: after:YYYY-MM-DD Filters documents indexed on or after this date. after:2024-01-01
before: before:YYYY-MM-DD Filters documents indexed on or before this date. before:2023-12-31
cache: cache:url Fetches Google's cached copy of the page. cache:example.com
related: related:url Discovers sites structurally similar to the target URL. related:github.com
Syntax Rule: Do not insert whitespace after the operator colon. site: example.com is invalid; site:example.com is valid.
